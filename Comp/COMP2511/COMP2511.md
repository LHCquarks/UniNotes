## Software Design and Architecture
This course aims to teach how to make sustainable, elegant software, using a systematic design and development strategy.
**Topics Covered**
- Object Oriented Programming
- Functional Oriented Programming
- How to structure a program well
## Learning Outcomes
- Create medium scale systems from scratch, and work on existing systems as part of the SDLC
- For specific software development scenarios, evaluate different design/architectural paradigms and methodologies based on their origins and suitability
- Create software solutions using an enterprise programming language within an integrated development environment (IDE)
## Assessment
- Assignment 1: Design an Object-Oriented Program from scratch (15%)
- Assignment 2: Software Design/Architecture - given a codebase, design a solution (15%)
- Labs: Eight labs worth 10 marks each, capped at 70 marks (15%)
## Assumed Knowledge
- Familiar with C and Python/JS programming concepts
- Able to work in a team (Git)
- Understand basic testing principles
- Understand Software Engineering design principles (DRY, KISS)
## Why use Java?
There are multiple reasons why it is useful to learn java:
- In the workplace, you don't get to choose the language
- Java is a good entry to Object-Oriented languages, and it is open source (as opposed to C#)
- Java compiles a `*.java` file to a `*.class` file (java byte class: high-level, not binary), which the JRE (Java Runtime Environment) can then run. This means that you can code a program which runs on every operating system (provided it has a JRE).
- Java has automatic memory management and does not require pointers.
- Java is strongly typed compared to C
- Java is multi-threaded - it gives you an easy way of using multiple cores (possible in C, but easy in Java)
- Java is more secure - it doesn't allow you to do go to memory spaces where you're not supposed to go
